4 Installing and loading the package

The package can be downloaded as a .tar.gz archive from https://gap-packages.github.io/sglppow/

Then tar -zxvf sglppow-2.6.tar.gz produces a directory sglppow-2.6. This should be moved into the pkg directory of a GAP installation.

The package is set up so that after loading it into GAP with LoadPackage("sglppow"); the full functionality of the package is available.
